# Prompt: Refactor

Usar para mejorar diseño sin cambiar comportamiento externo.

## Instrucciones

1. Definir el olor de código / deuda a atacar.
2. Localizar duplicación y puntos de extensión existentes.
3. Proponer refactor incremental (pasos pequeños).
4. Garantizar comportamiento observable igual (tests verdes).
5. No mezclar features nuevas en el mismo cambio.
6. Esperar aprobación antes de aplicar.

## Formato

- Objetivo del refactor
- Antes / después (diseño)
- Archivos afectados
- Riesgos
- Plan por pasos
- ¿Apruebas?
