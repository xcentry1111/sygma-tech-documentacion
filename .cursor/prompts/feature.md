# Prompt: Feature Implementation

Usar después de aprobar la arquitectura.

## Instrucciones

1. Confirmar el alcance aprobado (qué sí / qué no).
2. Implementar reutilizando Services, Models, Validators y Concerns existentes.
3. No duplicar lógica.
4. No romper contratos públicos sin documentarlo.
5. Incluir o actualizar tests según el patrón del repo.
6. Explicar archivos tocados y cómo probar.

## Checklist

- [ ] Flujo analizado
- [ ] Reutilización aplicada
- [ ] Sin acceso directo a DB
- [ ] Tests / plan de prueba
- [ ] Impacto documentado
